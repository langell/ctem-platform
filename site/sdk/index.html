CTEM-API v2.4

SDK

This is the CTEM gateway HTTP API. It is not a language SDK. Paths below are the routes in apps/api-gateway on this repo. Org comes from the bearer token (JWT or PAT). The client does not send an org id. Unauthenticated calls are 401 when the route exists.

Samples call $CTEM_GATEWAY with Authorization: Bearer $TOKEN. Response bodies that are not confirmed in the controller stay on the gateway’s /docs. No sample bodies here.

Health, OIDC, and login are not controllers under apps/api-gateway/src/routes/, so they are not in this reference. Scanners, connectors, and /internal paths are not listed.

Session

Echo of the principal this gateway minted for the bearer token. The client cannot supply an org id, and role and permissions for humans come from Membership.

GET /v1/session

Scans

Create a scan and read scans back, including the id CI and deploy tooling poll. The gateway forwards these routes to the orchestrator.

GET /v1/scans GET /v1/scans/:id POST /v1/scans POST /v1/scans/sbom

Assets

Assets are what findings hang off of, with criticality, owner, and exposure. The gateway forwards these routes to the asset service.

GET /v1/assets GET /v1/assets/:id GET /v1/assets/:id/graph POST /v1/assets/discover POST /v1/assets

Findings

Findings are the objects humans triage. List, get, and triage are forwarded to the findings service, and the risk read is forwarded to the risk service.

GET /v1/findings GET /v1/findings/:id GET /v1/findings/:id/risk PATCH /v1/findings/:id/triage

Policies

Policies say what to block, how fast a matching finding must be fixed, and who may accept the risk. Org comes from the token, and these routes forward to the risk service.

GET /v1/policies GET /v1/policies/:id POST /v1/policies PATCH /v1/policies/:id

Members

Members of the organization on the token. Invite, role change, and disable forward to the identity service and do not call the Keycloak Admin API.

GET /v1/org/members POST /v1/org/members PATCH /v1/org/members/:userId/role DELETE /v1/org/members/:userId

Meters

Read durable scan.kick usage for the organization on the token. This proxy does not emit a meter row, and a query orgId is dropped.

GET /v1/meters/scan-kicks

GET /v1/session

Returns the principal the gateway minted for this token.

Tag session. Permission: bearer principal. No extra permission decorator on the controller.

Response

Confirmed in the controller: userId, orgId, role, permissions, serviceAccount. Full schema: gateway /docs.

curl

curl -sS "$CTEM_GATEWAY/v1/session" \
  -H "Authorization: Bearer $TOKEN"

GET /v1/scans

Lists scans and forwards the query string to the orchestrator as the client sent it.

Tag scans. Permission scan:read.

The controller forwards the query as sent. This reference does not name list filters.

Response

Proxied. Full schema: gateway /docs.

curl

curl -sS "$CTEM_GATEWAY/v1/scans" \
  -H "Authorization: Bearer $TOKEN"

GET /v1/scans/:id

Returns one scan for CI and deploy tooling to poll. conclusion is computed from matching fail_build rules and deployConclusion from matching block_deploy rules, and this proxy has no write for either field.

Tag scans. Permission scan:read. CI and deploy tooling poll this.

conclusion is fail-build. deployConclusion is block-deploy. The client cannot POST either field.

Response

Partial. Confirmed fields on a scan include status (queued, running, succeeded, partial, failed, cancelled), conclusion (pending, passed, failed), and deployConclusion (pending, allowed, blocked). Full object: gateway /docs.

curl

curl -sS "$CTEM_GATEWAY/v1/scans/SCAN_ID" \
  -H "Authorization: Bearer $TOKEN"

POST /v1/scans

Creates a scan. An optional Idempotency-Key is forwarded so the orchestrator can dedupe the accept, and the gateway does not emit the scan.kick row.

Tag scans. Permission scan:run.

Optional Idempotency-Key is forwarded. The gateway does not emit the meter row.

Body

  • scannerType: sca, sast, container, iac, secrets, asm, or cloud_posture.
  • Optional assetSelector: assetIds (uuids), kinds, tags.
  • options object, default {}.
  • Optional externalId.

Do not send conclusion or deployConclusion.

Response

Proxied scan. Confirmed fields are the partial set on GET /v1/scans/:id. Full object: gateway /docs.

curl

curl -sS -X POST "$CTEM_GATEWAY/v1/scans" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"scannerType":"sca","assetSelector":{}}'

POST /v1/scans/sbom

Ingests an SBOM a CI system uploads instead of granting repository access. An optional Idempotency-Key is forwarded the same way as on scan create.

Tag scans. Permission scan:run.

Optional Idempotency-Key is forwarded. The gateway does not emit the meter row.

Body

  • assetExternalKey.
  • format: cyclonedx-json, spdx-json, or syft-json.
  • Exactly one of artifactKey or document.
  • Optional ref, commitSha, and externalId.

Response

Proxied. Full schema: gateway /docs.

curl

curl -sS -X POST "$CTEM_GATEWAY/v1/scans/sbom" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"assetExternalKey":"example.com","format":"cyclonedx-json","artifactKey":"objects/sbom.json"}'

POST /v1/assets

Upserts an asset and forwards the body to the asset service.

Tag assets. Permission asset:write.

Body

  • kind, externalKey, name, source.
  • Optional exposure, criticality, data classes, owner, tags, attributes.

Kinds: repository, package, container_image, cloud_resource, kubernetes_workload, host, domain, ip_range, web_application, api_endpoint, saas_app, iac_stack.

Response

Unknown beyond “returns the asset”. Schema: gateway /docs.

curl

curl -sS -X POST "$CTEM_GATEWAY/v1/assets" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"kind":"domain","externalKey":"example.com","name":"example.com","source":"asm"}'

PATCH /v1/findings/:id/triage

Sets one finding’s triage state and reason. expiresAt is optional on this controller; the policy service requires it when the state is risk_accepted.

Tag findings. Permission finding:triage.

Body

  • state: open, triaged, in_progress, resolved, risk_accepted, false_positive, or suppressed.
  • reason, 1–2000 characters.
  • Optional expiresAt. Required by the policy service when state is risk_accepted. That rule is enforced off this controller, not as a gateway check.

Response

Unknown (proxied). Schema: gateway /docs.

curl

curl -sS -X PATCH "$CTEM_GATEWAY/v1/findings/FINDING_ID/triage" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"state":"triaged","reason":"Owner assigned"}'

POST /v1/policies

Creates a policy and forwards it to the risk service. Tenant webhook and Jira URL fields are refused.

Tag policies. Permission policy:write. Org comes from the token.

Body

  • name, condition, and actions.
  • actions is a non-empty subset of notify, ticket, fail_build, and block_deploy. ignore is not an editor action.
  • Optional description, enabled, priority, and slaHours.

Tenant webhook and Jira URL fields are refused.

Response

Unknown (proxied). Schema: gateway /docs.

curl

curl -sS -X POST "$CTEM_GATEWAY/v1/policies" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Block high risk deploys","condition":{"minRiskScore":70},"actions":["block_deploy"]}'

Tag policies. Permission policy:write. Org comes from the token.

GET /v1/meters/scan-kicks

Lists durable scan.kick rows for the token’s organization and does not emit a meter row. When neither from nor to is set, the window is the last 30×24 hours with no upper bound; setting either bound disables that default.

Tag meters. Permission scan:read. Read-only.

Query orgId is dropped. This route does not emit a meter row.

Query

  • Optional from and to, ISO-8601. from is inclusive. to is exclusive.
  • source: manual, api, webhook, ci, or schedule.
  • limit default 50, cap 200. Optional cursor.

Response

Unknown (list shape not read from the controller). Schema: gateway /docs. Summary confirmed: scan.kick usage for the token’s organization.

curl

curl -sS "$CTEM_GATEWAY/v1/meters/scan-kicks?source=ci&limit=50" \
  -H "Authorization: Bearer $TOKEN"
